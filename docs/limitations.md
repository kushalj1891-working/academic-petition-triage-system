# Implementation status and limitations

This is a runnable teaching demonstrator and a decision-support prototype. It never makes the university's final decision. The default local agent is deterministic, not an LLM; prompt variants are versioned evaluation artifacts, but no model is called, so observed prompt-comparison/model-token/cost results are not applicable. A model identifier is injected only through local runtime configuration. The measured metrics generated by `evals/run_eval.py` are local deterministic path checks only.

The implementation includes REST schema/range/category validation, queueing, quarantine-by-rejection at request validation, a two-query attendance path, three distinct graph roles, four tools, exact citation verification, prompt version labels, a 20-scenario evaluation set, injection-resistant routing rules, structured JSON logs, Prometheus scrape metrics, Redis rate limiting, local lexical fallback, retry-safe client polling, and feedback persistence.

Not yet production-complete: per-agent dashboard panels, aggregate run reconstruction of every passage/query, configurable provider circuit breaker and exponential external-model retry (no model provider is wired), reliable dead-letter quarantine for malformed raw JSON, persistent whole-run result caching, latency/cost comparison with `--scale agent-worker>=3`, real model-token/cost accounting, prompt A/B measurement, automated live-run quality sampling, and formal Locust SLO results. Vector retrieval has a local breaker and lexical fallback; citation verification performs one bounded recovery search, and worker execution times out after 60 seconds. The evaluation baseline is unavailable; run measurements and record them rather than inventing before/after metrics. The per-request limiter uses client IP and Redis fixed windows; it is a classroom control rather than an abuse-resistant identity system.

Security/data: only synthetic petitions are permitted. Do not enter real student PII or medical details. No credentials or model endpoints are committed. Grafana's default demo password must be changed if exposed beyond localhost.
